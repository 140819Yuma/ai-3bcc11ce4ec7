# 【このファイルの役割】
# masking.py の ALLOW_WORDS はホワイトリストの土台で、コードに埋め込んである。
# 案件ごとに増える業務語をコードに書き足していくと管理できなくなるため、
# 追加分はここに置く。git 追跡下にあるので、アカウントが変わっても引き継がれる。

# 【追加してよいもの】
#   会計・業務の一般語（費目名、事業の型、契約の形態、単位や構造を表す語）
#
# 【絶対に追加してはいけないもの】
#   氏名・姓・名、団体名、商号、ブランド名、地名、施設名
#   → 許可語は「それ単独で通る」だけでなく「組み合わせても通る」ようになる。
#     例えば「起業」と「支援」を許可すると、それを名乗る団体名も素通りする。
#     固有名詞になりうる語は入れないこと。
#
# 【語彙を増やすとき】
#   python3 masking.py --review   で伏字化された語の候補一覧が出る（ローカルのみ）。
#   目視で業務語だけを選び、ここへ移す。候補ファイルそのものは公開しないこと。
