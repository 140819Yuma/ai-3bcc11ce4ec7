# 予算データの記入要領

財務予測AIに予算を渡すためのフォーマットです。`template_予算.csv` に例が入っています。
Excelで編集し、**CSV（UTF-8）で保存**してください。

## なぜPDFではなくCSVでお願いしているか

見積書PDFからも読み取れるようにはなりましたが、**PDFは表の構造が失われる**ため、
どの数値が単価でどれが金額かを機械が判別できず、精度が落ちます。実際に読み取った
ところ、明細と大項目の金額が突き合わない箇所が複数出ました。

CSVなら列の意味が確定するので、この誤りが構造的に起きなくなります。

## 列の説明

| 列 | 必須 | 内容 |
|---|---|---|
| プロジェクト | ○ | 案件名。社内での呼び名で構いません |
| 年度 | ○ | 西暦4桁。**4月始まりの年度**（2026年度＝2026-04〜2027-03） |
| 大項目 | ○ | 見積書の大きな区切り |
| 区分 | ○ | **`事業費` または `人件費・管理費`** のどちらか |
| 明細 | ○ | 費目の名前 |
| 単価 | | 1単位あたりの金額。**空欄でも構いません**（下記参照） |
| 数量 | ◎ | 日数・回数・件数・月数。**ここが最も重要です** |
| 単位 | ◎ | `日` `回` `件` `月` `名` `式` のいずれか |
| 金額 | ○ | 単価×数量の結果。税抜 |
| 備考 | ◎ | 執行の条件。下記の書き方を参照 |

## ◎ の3列が予測精度を決めます

AIが判断しているのは「使った/使っていない」ではなく、**その費目が構造的に
どう発生するか**です。次の3つを区別しています。

| 型 | 例 | 判断されること |
|---|---|---|
| **稼働日ベース** | 0.5日/月×12か月 | **経過した月の分は後から積めない。**遅れがそのまま使い残しになる |
| **件数ベース** | 1件50,000円×8件 | 採択できる案件が8件無ければ執行されない。母集団の制約を受ける |
| **年額・月額契約** | 月額2,500円×12か月 | 止まらないので確実な下限になる |

`数量` `単位` `備考` が空だと**この区別ができず**、「予算額に対して何割使ったか」
という粗い計算しかできなくなります。

## 備考の書き方

執行の条件を短く書いてください。文章で構いません。

```
0.5日/月×12か月稼働          ← 稼働日ベースだと分かる
年3回開催                     ← 回数ベースだと分かる
1件あたり50000円・採択件数に依存  ← 件数ベースで母集団に依存すると分かる
年間契約・月額固定             ← 止まらない固定費だと分かる
7月開始・開始が遅れると月割で減る  ← 開始時期の制約が分かる
納品が翌年度になる場合は当年度計上不可  ← 年度またぎの制約が分かる
```

## 単価は空欄でも構いません

**日単価は社外に出したくない情報**だと理解しています。空欄にしていただいて
問題ありません。`数量` `単位` `金額` があれば予測は成立します。

同様に、**人件費の明細に個人名を書く必要はありません**。「企画・進行」「現場運営」
のような役割名で十分です。複数名分をまとめた金額でも構いません。

## よくある確認事項

**Q. 一般管理費はどう書きますか**
A. 明細の1行として入れてください（`明細=一般管理費`、`備考=小計の10%`）。

**Q. 金額が未定の費目は**
A. `金額` を空欄にし、`備考` に「未定」と書いてください。空欄は空欄として扱い、
0円とは区別します。

**Q. 数量0の費目があります**
A. そのまま `0` と書いてください。「枠はあるが執行予定なし」と正しく判断されます。

**Q. 途中で予算を変更したら**
A. 変更後の版を新しいCSVとして送ってください。差分は不要です。
